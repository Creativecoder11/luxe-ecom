Change from version 1.0:
- Replaces electronics/gadgets-only positioning with any-category catalogue (beauty, fashion, gadgets, etc.)
- Adds OMS + manually entered Facebook/phone orders, CRM, call-center workflows, purchase and inventory, courier management, messaging, invoicing, reporting and ERP extension strategy
- Sets clear delivery phases, provider dependencies and secure integration behavior

Scope assumption: business-operated commerce across channels, not a ready-made third-party multivendor SaaS marketplace. Multi-business tenancy is optional future architecture.
Release 1: commerce + OMS + stock/purchasing essentials + CRM + manual courier + invoices + dashboards + COD.
Release 2: connected Meta/couriers/payments/SMS/voice + POS/wholesale + expanded inventory/finance according to requirements.
Release 3: optional dealer, SR, production, supply chain, LC/import-export, HR, approvals, multi-business ERP extensions.
External providers must be contracted/configured/tested before their capabilities are labelled active.
